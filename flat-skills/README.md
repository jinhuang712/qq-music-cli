# Flat-channel skills (generated)

Pi and OpenCode list skills without a plugin namespace. Here the skill is therefore named `qq-music-cli`, while
Claude Code and Codex show `skills/cli` as `qq-music:cli`.

Do not edit `qq-music-cli/` by hand. Edit `skills/cli/`, then run:

```sh
uv run python scripts/sync_flat_skill.py
```

`tests/test_manifests.py` fails when this copy drifts from the source.
